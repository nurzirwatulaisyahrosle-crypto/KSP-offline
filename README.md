# Kembara Si PeTara — Versi Luar Talian

Ini ialah projek **berasingan** daripada [KSP-V2 Online](https://nurzirwatulaisyahrosle-crypto.github.io/KSP-V2/). Fail dalam repositori online tidak diubah.

## Cara terbitkan pautan kali pertama
1. Pergi ke **Settings > Pages** dalam repositori ini.
2. Di **Build and deployment**, pilih **Deploy from a branch**.
3. Pilih **main** dan **/(root)**, kemudian tekan **Save**.
4. Pautan permainan ialah https://nurzirwatulaisyahrosle-crypto.github.io/KSP-offline/

## Cara simpan untuk kegunaan offline
1. Semasa masih mempunyai Internet, buka pautan KSP-offline dan tunggu paparan **Offline tersedia**.
2. Pada iPhone (Safari), tekan **Share > Add to Home Screen**. Buka aplikasi daripada ikon Skrin Utama selepas itu.
3. Cuba mod kapal terbang sebelum pertandingan: buka aplikasi, uji peta, audio dan Misi 1–2.

## Had yang perlu diketahui
- Peta, imej, avatar, audio dan Misi 1–2 boleh digunakan tanpa Internet **selepas fail cache disimpan sepenuhnya**.
- Misi 3–5 menggunakan Web Speech Recognition dari pelayar; pengecaman pertuturan **mungkin memerlukan Internet**, terutamanya pada iPhone. Mod offline tidak menjamin semakan suara.
- Pemain lain/multiplayer sengaja dinyahaktifkan di repositori offline kerana Firebase memerlukan Internet.
- Fail aset asal dimuat turun daripada KSP-V2 **sekali semasa pemasangan pertama**, kemudian dicache secara setempat. KSP-V2 sendiri tidak diubah.
- Cache pelayar boleh dipadam oleh sistem; selalu uji sebelum menggunakannya tanpa Internet.
