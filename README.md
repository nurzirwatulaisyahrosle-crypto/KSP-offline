# Kembara Si PeTara — Offline

Repositori berasingan untuk membangunkan versi **offline** Kembara Si PeTara.

## Tujuan
Versi ini akan menggunakan permainan KSP-V2 sebagai asas, tanpa sistem Firebase / multiplayer yang memaparkan avatar pemain lain.

## Keperluan sebelum versi offline boleh digunakan
- Salin fail permainan, imej, animasi dan audio daripada KSP-V2.
- Sediakan aset tempatan dan mekanisme cache/pemasangan untuk membolehkan permainan dimainkan tanpa Internet.
- Kekalkan 5 misi, pilihan nama/avatar, peta, butang HOME dan fungsi mula semula.
- Semak dan sesuaikan pengecaman suara Misi 3–5; Web Speech API tidak boleh dijamin berfungsi sepenuhnya tanpa Internet.
- Uji dengan Internet dimatikan pada peranti sebenar.

**Status:** Repositori telah dicipta. Salinan lengkap permainan offline belum siap.

**Nota:** Versi asal KSP-V2 online tidak diubah oleh repositori ini.
